# Moti Properties

A full-stack real estate web application built with Next.js and MySQL, featuring user authentication and property listings.

##  About

Moti Properties is a real estate platform where users can browse property listings, register accounts, and log in securely. The project was built to demonstrate full-stack development skills, including database design, authentication, and responsive UI.

##  Features

-  User authentication (registration and login) with hashed passwords and role selection
-  Property listings fetched from a MySQL database
-  Search and filter listings by price range, property type, and location
-  Property application form with input validation
-  Responsive design with reusable components (NavBar, Footer)
-  Client-side routing with Next.js
-  Testimonials section

## Tech Stack

- **Frontend:** React, Next.js
- **Backend:** Next.js API Routes (Node.js)
- **Database:** MySQL
- **Other:** mysql2 for database queries

##  Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or later recommended)
- [MySQL](https://www.mysql.com/) installed and running locally
